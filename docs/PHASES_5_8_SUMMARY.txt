  ✅ 10 core methods implemented
  ✅ createOutcome() (record execution outcome)

  ✅ calculateReward() (deterministic score computation)
  ✅ Explicit score support (objectiveResult.score)
  ✅ Formula-based evaluation (success, quality, speed, cost)
  ✅ Safety penalty application
  ✅ auditCalculation() (governance review)

Reward Calculation:
  ✅ Deterministic (no randomness)
  ✅ Base score (0-100 scale)
    - Success: 90 (false: 20)
    - Quality metric adjustment
    - Speed bonus (< 60 sec: +5)
    - Cost penalty (> $100: -cost/10)
  ✅ Safety penalties:
    - Protected surface touch: -15
    - Each side effect: -2
    - Each policy violation: -5
    - Simulation mislabeled: -20
  ✅ Final score = max(0, baseScore - penalties)

Immutability:
  ✅ Calculations written once, never updated
  ✅ Trigger prevents UPDATE on reward_calculations
  ✅ Audit trail immutable

Versioning:
  ✅ Reward functions versioned (name+domain+version UNIQUE)
  ✅ New formula = new version
  ✅ Old formulas remain for historical calculations

  ✅ POST /api/outcomes
  ✅ POST /api/reward-functions
  ✅ POST /api/outcomes/:outcomeId/calculate-reward
  ✅ GET /api/reward-functions
