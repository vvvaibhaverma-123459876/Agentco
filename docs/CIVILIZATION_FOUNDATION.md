# Civilization Foundation

Agentco's civilization architecture starts from calibration.

The intended progression is:

Calibration / Epistemic Reserve -> Agent reputation -> Department / Team reputation -> Institution authority -> Society governance -> Civilization constitution.

## Foundation Principle

Calibration is the epistemic constitution. No entity may gain trust, reputation, authority, jurisdiction, budget, or governance power from unresolved, self-certified, circularly verified, disputed, or non-independent claims.

## Current Foundation

- Claims can be pre-registered.
- Resolution can be checked against external evidence where implemented.
- Trust can be updated from resolved evidence.
- Credentials can be recomputed.
- Institutions can model departments, members, reviews, governance, memory, and reputation at a bounded kernel level.

## Current Boundary

Agentco does not yet ship a production Society or Civilization layer. Society governance, jurisdiction, judiciary, economy, constitution, law registry, and civilizational memory remain future gated phases.
