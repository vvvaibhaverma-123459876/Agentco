### Repair 2: Create/Update Routes to Call Services

**Option A: Create New Routes File**

Create `backend/src/routes/autonomy-orchestrator.routes.ts`:

```typescript
import { FastifyInstance } from 'fastify';
import { autonomyOrchestrator } from '../services/autonomy-orchestrator.service';

export async function autonomyOrchestratorRoutes(fastify: FastifyInstance) {
  fastify.post('/api/autonomy/run-level3-smoke', async (request, reply) => {
    try {
      const run = await autonomyOrchestrator.executeControlledAutonomyLoop();
      reply.code(200).send({
        status: 'success',
        run,
      });
    } catch (error: any) {
      reply.code(500).send({
        status: 'error',
        error: error.message,
      });
    }
  });
}
```

**Option B: Add Routes to Existing File**

Update `backend/src/routes/autonomy-tasks.routes.ts` to also import and use learner, eval, and self-mod services.

**Decision:** Option A (separate file, cleaner)

**Time:** 15 minutes
