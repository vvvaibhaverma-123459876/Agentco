# Agentco North Star

Status: **PARTIAL** as R&D framing only.

This file preserves the long-range vision: Agentco may grow from an evidence-governed control plane into a governed substrate for autonomous learning systems, institutions, simulation labs, trace-to-training-data pipelines, model foundry workflows, and successor-model research.

This is not a present-tense product claim. The README, API, dashboards, tests, and operator docs must not claim these capabilities as shipped until their phase gates pass.

The long-range trajectory remains:

- Evidence Kernel and source independence become the trust substrate.
- Durable execution, provenance, and attestation make actions externally verifiable.
- Memory, learning, dynamic agents, governance, institutions, and societies are built only over gated lower layers.
- Simulation remains quarantined until externally validated.
- Self-modification is sandboxed, governed, reversible, and denied on protected surfaces unless high-risk governance explicitly approves it.
- Model Foundry is a governed trace-to-training-data pipeline, not an AGI claim.

The north-star test is whether future Agentco systems can learn from reality without circular verification, preserve provenance, quantify uncertainty, and subject consequential actions to mechanically enforced policy.
