# Current Capabilities

Agentco is civilization-grade AI infrastructure beginning with calibration. The executable foundation today is calibration-first, not a completed civilization operating system.

## Executable Foundation

- Pre-registered prediction ledger.
- Resolution service and source-independence helpers where implemented.
- Trust scoring based on resolved calibration evidence.
- Audit trails and append-only/hash-chain primitives where implemented.
- Recomputable Proof-of-Calibration credentials.
- A bounded Institution Kernel with Institution -> Department -> Agent modeling, review workflow, governance decisions, memory events, and reputation propagation.

## Civilization-Side Implementation

- Institution -> Department -> Agent substrate exists.
- Institution contracts and anti-chaos controls exist.
- Society and Civilization are not production-grade layers yet.

## Not Yet Shipped As Production Civilization

- Society coordination.
- Constitution and law registry.
- Jurisdiction engine.
- Dispute judiciary.
- Institutional economy.
- Civilizational memory and precedent system.
- Lifecycle evolution for societies and full civilization entities.

## External Service Notes

Tests and demos must not require paid external LLM APIs. Where model calls are needed, use deterministic mocks or local/offline providers.
