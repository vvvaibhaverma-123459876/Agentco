## Root Cause

`scripts/run_cross_version_campaign.py` used `deterministic_output()` and
subject-specific branches for `version-a` and `version-b`. It also derived
latency/resource metrics from feature flags and assigned constant governance,
budget, tool reliability and recovery values.

## Corrective Controls

- Replaced synthetic output generation with subject process invocation.
- Added `subject-benchmark-v1` request/response schemas.
- Added external adapter contracts that return `unsupported` instead of fake
  answers when a subject lacks the protocol.
- Added harness independence validator.
- Added runtime-origin evidence verifier.
- Added anti-gaming regression tests.
- Added blinded opaque subject labels during scoring.
