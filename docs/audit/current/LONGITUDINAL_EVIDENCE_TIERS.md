# Longitudinal Evidence Tiers

- Tier L0 — Structural: code/config/docs exist; no behaviour proven.
- Tier L1 — Single execution: one workflow completed once.
- Tier L2 — Repeated execution: same version completed independently seeded runs.
- Tier L3 — Cross-version evidence: multiple committed versions compared on frozen benchmarks.
- Tier L4 — Short temporal evidence: at least four calendar weeks.
- Tier L5 — Longitudinal evidence: at least twelve calendar weeks, multiple releases, multiple domains.
- Tier L6 — Hosted longitudinal evidence: verified hosted infrastructure across time.
- Tier L7 — Production longitudinal evidence: production-real responsibilities and independent review.

Reports must calculate L4-L7 from immutable timestamps; same-day runs cannot satisfy calendar tiers.
