## Adapter Implementation

The new campaign `subject-native-cross-version-v1` uses detached immutable
worktrees and invokes the existing provider-free durable calibration path:

```text

```

The adapter does not read hidden expectations, generate benchmark answers, or
branch on subject labels. The benchmark request hash is written to the subject
task payload and must be echoed by the subject result as `prediction_id`.
