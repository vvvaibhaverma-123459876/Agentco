# Longitudinal Run Protocol

Every run records exact commit, branch, dirty status, benchmark registry hash, evaluator version, seed, environment, provider classification, budgets, timeouts, input/output hashes, command ledger, failures, cost estimates, approvals, evidence hashes, and parent runs. Allowed provider classifications are: deterministic_fixture, simulated, local_model, local_real_service, live_external_provider, hosted_staging, production.
