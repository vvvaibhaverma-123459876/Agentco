## Independent Post-Remediation Re-Audit Checklist

Before a final production-ready verdict, re-audit without relying on the original findings:

- run `make release-gate` from a clean worktree
- review the diff for weakened tests, new skips, force exits, or raw success fallbacks
- search for new TODO/stub/mock/fallback paths introduced by remediation
- verify generated docs match implementation after tests regenerate reports
- render Helm templates with the real Helm binary
- build and smoke-test containers
- verify no production path selects an in-memory governance, evaluation, learning, experiment, or budget adapter silently
