# Experiments Boundary

This directory contains research artifacts: pre-registrations, frozen models, CSV/JSON outputs, and experiment reports.

These files are not required for the core Agentco runtime, backend API, calibration ledger, resolution service, or Proof-of-Calibration credential path. They are retained as optional evidence and may be moved to a research archive or separate repository later.

Production install and verification should treat this directory as optional unless a specific acceptance gate explicitly references a file here.
